# 学说对照模板（Doctrine Contrast）

当刑法问题存在学说竞争时，使用本模板。核心纪律：**每个学说是一个独立的价值立场，必须单独给出结论**；对照表是强制产物，不是「列出各方观点」的软性段落。

## 一、争议判定

回答三个问题：

1. 该问题的竞争发生在哪一层？
   - 价值立场层（如：违法性本质是法益侵害还是规范违反）
   - 体系前提层（如：四要件 vs 阶层体系）
   - 解释方法层（如：具体符合说 vs 法定符合说）
2. 各方是否可能对同一案件得出**不同结论**？——若各方结论相同，只是论证不同，则不是真正的学说竞争，写明「结论一致，分歧在论证」即可，不要制造虚假对照。
3. 是否存在「通说」？在哪个范围内（学界通说 / 法考通说 / 实务立场）？

## 二、现行法基线（先于学说）

- 条文：`刑法第X条` 要件与效果。未核验写「条文待核验」。
- 司法解释 / 指导案例立场（如有）。
- 法考标准答案（客观题选项、主观题采分点）。

本段是锚点：后续所有学说对照都相对于它展开，不得被学说改写。

## 三、学说对照表

每行一个学说。**「该学说下的结论」列是硬要求**——必须是对当前问题的明确答案，禁止「各有道理」「视情况」「一般认为」。

| 学说 | 代表学者 | 价值立场/规范承诺 | 核心论证（含最强反对意见） | 该学说下的结论 | 来源（书/页） |

| 学说A |  |  |  |  |  |
| 学说B |  |  |  |  |  |
| 学说C |  |  |  |  |  |

### 每学说展开时的价值层速查（可对每个学说各跑一遍）

对学说竞争的问题，每个学说背后都有一套「为什么」——这正是 `normative-value-analysis.md` 的价值层在学说层面的应用：

- 该学说把什么认定为**核心法益或核心规范**（保护谁）？
- 该学说的结论让**谁承担代价**（如：结果无价值论下某些未遂/不能犯出罪，谁受益）？
- 该学说最强的**反对意见**是什么（来自哪个对立学说）？
- 该学说在德国法中的对应物及德国主流态度。

## 四、法考采信与理由

- 明确写出法考立场（哪家 / 哪家为主 / 哪家例外）。
- 决定性理由（通常与法考命题人立场、法条表述、司法解释一致）。
- 速记句：一句可背的判断。

## 六、边界案例与变体

- 边界案例 A（像 A 实为 B）与边界案例 B（像 B 实为 A）：各用一句话案情，标注关键事实。
- 关键变量：不超过 3 个词。
- 变体练习：改一个事实让结论翻转，附答案（空行分隔，供自测）。

## 七、落盘

写入 `study_note/刑法/`，frontmatter 建议：

```yaml
---
aliases: [...]
tags: [刑法, 学说对照, <争议领域>]
created: <date>
doctrine_contrast: true
verdict_source: <法考立场出处>
---
```

## 压缩模式（快速答题时）

只保留：① 争议一句话；② 三行对照表（学说/结论/法考采信）；③ 速记句。其余段跳过，但禁止在压缩模式下省略「每个学说的结论」。
