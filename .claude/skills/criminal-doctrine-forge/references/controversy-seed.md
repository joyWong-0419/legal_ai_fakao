# 刑法争议种子清单（Controversy Seed）

> 用途：`criminal-doctrine-forge` 判定争议性时的对照清单。命中即走完整学说对照；未命中则声明通说一致。
> 纪律：表中「法考大致立场」仅为**待核验线索**，使用前必须以现行法、官方教材或真题核验；不得把本清单当作已核验结论。已建卡的争议在「状态」列链接到 `study_note/刑法/` 中的笔记。

## 使用提示

1. 命中本表争议点时，必须走 `references/doctrine-contrast.md` 完整对照流程。
2. 表外问题：先判断是否真有学说竞争；「结论一致、仅论证不同」的问题按通说直接作答。
3. 建卡后把链接回填到「状态」列，让本表成为争议索引的总入口。
4. 法考立场列是线索不是结论——每次使用前用现行教材/真题核验。
